# ⏳ Countdown Timer

### Veda Technology – Web Development Internship | Task 13

A professional and responsive countdown timer built using **HTML5, CSS3, and JavaScript**. The application counts down to a configurable target date and displays the remaining days, hours, minutes, and seconds in real time.

---

## 📌 Project Overview

The Countdown Timer is a frontend web application developed as part of **Task 13** of the Veda Technology Web Development Internship.

The project demonstrates practical implementation of:

- JavaScript Date and time calculations
- Real-time DOM updates
- `setInterval()`
- `clearInterval()`
- CSS Grid and Flexbox
- Responsive web design
- CSS hover effects
- Progress indicators
- Countdown completion handling

---

## 🎯 Objective

The main objective of this project is to create a countdown timer that:

- Counts down to a specific date and time
- Displays days, hours, minutes, and seconds
- Updates automatically every second
- Allows the target date to be configured in JavaScript
- Displays a completion message when the countdown reaches zero
- Stops the timer after completion
- Works across desktop, tablet, and mobile devices
